# The Milano Seal™ — Packaging & Delivery SOP

## Locked core delivery flow

1. RON / execution completed when applicable.
2. Apostille / authentication received when applicable.
3. Client release slip printed and handwritten when used.
4. Packet assembled in the approved stack order.
5. Packet placed in the presentation folder when the matter uses one.
6. Folder / packet placed into the approved courier envelope.
7. Courier label and destination verified before drop-off.
8. Drop before the applicable carrier cutoff.
9. Tracking attached to the Matter and custody chain.
10. Delivery confirmation closes the physical-release portion of the Matter.

No delivery step may bypass payment, QA, custody, or release authorization.

## Packet stack order

1. Milano Seal client slip / release insert when used.
2. Apostille or authentication certificate original when applicable.
3. Underlying notarized / executed document.
4. Optional copy set only when requested or required.

## Standard supply kit

### Presentation
- 9 × 12 matte-black presentation folder
- matte / soft-touch finish only
- no gloss

### Slip
- cream / soft-white cardstock
- A6 (approximately 4.1 × 5.8 inches)
- premium black ink for handwritten greeting / signature

### Shipping
- document courier envelope appropriate to the route
- prepaid / approved label tied to the Matter
- dedicated secure Milano Seal storage bin / drawer before release

## Print controls

### Folder
- final size: 9 × 12 inches
- print at 100%; no auto-fit
- centered Milano Seal mark on front
- minimalist layout
- matte black substrate
- metallic-gold simulation or foil when production method supports it

### A6 insert
- approximately 4.1 × 5.8 inches
- cream or soft-white cardstock
- centered typography and wide margins
- signature / greeting area may remain blank for handwritten completion

## Future premium production

Future foil / emboss production may use:

- approved vector logo
- dedicated foil layer
- emboss / deboss alignment file
- printer-approved dieline and stamping plate

This future print treatment does not change digital custody, Matter, payment, or release logic.
