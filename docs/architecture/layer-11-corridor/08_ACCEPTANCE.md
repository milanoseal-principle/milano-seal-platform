# Acceptance

Layer-specific 10/10 acceptance is defined in `../../LAYER_MANIFEST.json`.

Every layer must answer:
1. WHO OWNS THIS TRUTH?
2. WHAT STATE CAN IT CHANGE?
3. WHAT EVIDENCE IS REQUIRED?
4. WHAT TEST PROVES IT?

Documentation alone never certifies production. Acceptance requires current code, durable evidence, green tests, and exact deployed-SHA verification where the layer participates in runtime behavior.
