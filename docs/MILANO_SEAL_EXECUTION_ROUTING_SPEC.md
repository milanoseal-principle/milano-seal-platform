# Milano Seal Execution Routing Spec

The execution routing upgrade maps document execution intake to operator/jurisdiction/service-lane routing, execution readiness scoring, matter lifecycle, referral attribution, message templates, send-off assets, entity boundaries, proof loop, and operator QA.

Payment-gated execution remains protected. Missing signer location, missing document type, destination gaps, RON jurisdiction uncertainty, and custody/shipping gaps route to operator review before scheduling.
