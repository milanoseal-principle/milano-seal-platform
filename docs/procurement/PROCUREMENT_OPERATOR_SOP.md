# Procurement Operator SOP

Daily operator flow for the Universal Procurement Engine (rendered inside
`/dashboard/government` → Procurement Command Center).

1. Open the Procurement Command Center → **Today**. Clear urgent actions first.
2. **Opportunities**: record only verified opportunities (source URL / portal). Unknown fields stay null.
3. **Bid Decisions**: run the existing bid/no-bid engine; a recommendation is never an award prediction.
4. **Compliance**: no requirement is satisfied without evidence.
5. **Proposal Workspace**: assemble from canonical sections; agency-specific sections authored per opportunity.
6. **Pricing**: government pricing is operator-prepared (no auto public price); margins stay internal.
7. **References / Insurance**: only confirmed consent / bound evidence counts.
8. **Submissions / Recorded Submissions**: keep status accurate; awards require documented evidence.

Boundaries: administrative coordination only — no legal, medical, or immigration advice. No government/airport/TSA/airline endorsement.
