# Airport Relationship & Sponsorship Playbook

A deliberately conservative pathway. Order matters:

1. **Relationship first** — build a genuine airport / airport-adjacent relationship.
2. **Referral relationship before any sponsorship request.**
3. **Vendor registration before any operational claim.**
4. Operational use case established through registered, authorized channels.
5. Only then explore a possible sponsor-supported credential pathway.

Hard boundaries — never claim:
- restricted-area / secure-side / SIDA access is assumed
- TSA certification or clearance
- airport approval or airline approval
- badge approved

Sponsorship does **not** guarantee badging. Restricted-area access is never assumed.
